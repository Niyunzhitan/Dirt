# 文档目录

该目录保存不会直接参与网站运行的项目资料。

其中，[普通用户使用说明](./User-Safari.md)介绍网站的浏览路线、地图与 3D 交互、AI 助手、趣味问答以及显示设置。显示设置中的“墨玉”是深色模式，“昼夜自动”会按照本地时间在浅色和深色之间切换。

```text
docs/
├─ deployment/          阿里云函数计算部署说明
├─ research/            答辩稿、PPT 导出页和资料提取文本
└─ qa/screenshots/      开发过程中的桌面端与手机端验收截图
```

网页运行需要的图片仍保存在根目录的 `assets/` 中。不要把页面正在引用的图片移动到这里，否则需要同步修改 HTML 或数据文件中的路径。
