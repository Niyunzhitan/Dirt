# 泥云智探使用说明

这份说明写给普通访客。你可以直接浏览网站，不需要了解代码。

## 打开网站

在线使用时直接打开网站地址。

本地运行时，在项目目录执行：

```powershell
npm install
npm start
```

然后打开 `http://127.0.0.1:3000`。也可以双击根目录的 `index.html` 浏览静态内容，但数据库和 AI 功能可能不可用。

## 首页导航

顶部导航包含这些栏目：

- 认识封泥
- 封泥故事
- 齐鲁封泥图鉴
- 调研足迹
- 支教课程资源
- 封泥牌具
- 问问 AI
- 趣味问答

手机或窄窗口下，导航会收进菜单按钮。

## 搜索

点击右上角“搜索”，输入印文、地点或行政名称，例如：

```text
临淄
守印
仓府
泰山郡
```

结果会分为代表藏品和区县图录。点击结果后，页面会定位到对应内容。

## 认识封泥

数字手卷讲一封古代文书如何写下、系绳、覆泥、钤印、传递和验封。

手卷支持：

- 点击左右箭头翻页；
- 在手卷上左右拖动；
- 使用鼠标滚轮横向翻阅；
- 点击手卷后使用键盘左右方向键；
- 在手机上左右滑动。

手卷下方的四张封泥图片可以点击。点击后会跳到“齐鲁封泥图鉴”的对应卡片。

## 封泥故事

点击故事卡片即可阅读详细内容。故事分别讲秦代宫廷日常、陈介祺与金石考证、齐都故城的地方制度，以及仓府盐铁和漕运凭信。

## 齐鲁封泥图鉴

图鉴展示几件代表藏品。卡片中可以查看图片、年代、研究价值和说明。

点击卡片下方的图录按钮：

- 临淄守印会定位到完整图录中的临淄区资料；
- 其他藏品会打开完整图录，并按相关印文进行搜索；
- 如果完整图录没有同名条目，弹窗会明确提示，不会把藏品错误绑定到其他地点。

## 调研足迹和完整图录

3D 地图展示山东封泥资料点位。点击地图上的点位，可以查看地点、年代和资料数量。

点击右侧“在完整图录中查看”，会打开完整图录，并自动填入当前县名。

地图上方可以按青州、兖州、徐州等体系筛选。地图支持拖动、滚轮缩放、双击复位和抬升角度调整。

地图用于文化展示，不是测绘或导航工具。

## 支教课程资源

课程栏目包含三课时课件、支教活动回顾视频和可下载的教案学习单。

切换课时后，使用左右按钮或方向键翻阅课件，也可以打开原始 PDF。

## 封泥牌具

“封泥牌具”展示扑克牌和麻将主题 3D 模型。

- 拖动模型可以旋转；
- 滚轮可以缩放；
- 双击可以翻面；
- “扑克牌”和“麻将”按钮可以切换类型；
- 上一件、下一件可以浏览同类牌具；
- “暂停旋转”“复位”和“全屏”按钮分别控制自动旋转、视角和全屏模式。

## 印小灵和 AI

右下角的印小灵可以打开快捷对话。页面下方还有完整 AI 区域，可以提问、上传封泥图片、请求文字识读建议，或了解封缄、官制和历史地理。

AI 结果只适合辅助学习。残缺或有争议的文字仍需要专业人员复核。

## 趣味问答

每轮会随机抽取题目。选择答案后点击确认，页面会显示对错和解析，完成后可以查看成绩或重新开始。

## 显示设置

右上角齿轮可以调整：

- 浅色、深色或昼夜自动主题；
- 字号和行距；
- 页面动效、卡片倾斜和背景微尘；
- 开屏动画和印小灵；
- 背景音乐和音量。

这些设置保存在当前浏览器中，不会影响其他访客。

## 常见问题

**开屏动画太久：** 在显示设置中关闭开屏动画，刷新后会直接进入正文。

**地图空白：** 等待地图加载，或刷新页面。浏览器需要支持 WebGL。

**AI 没有回答：** 检查网络和服务端配置，稍后再试。

**图片上传：** 上传前请确认图片中没有身份证件、联系方式或其他不希望发送到 AI 服务的内容。
