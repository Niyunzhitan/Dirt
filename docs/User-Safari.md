# 泥云智探使用说明

直接用浏览器打开网站即可，无需安装软件。本说明介绍各栏目的操作方法和常见问题。

## 页面导航

点击顶部导航可前往各栏目。使用手机或较窄的窗口时，先点导航栏中间的菜单按钮，再选择栏目。

打开网站时，页面默认播放卷轴开屏动画，进度条下方会轮换封泥小知识。你可以打开右上角设置，在“动态效果”中关闭“开启开屏动画”。下次刷新时，页面便会直接显示正文。

## 搜索资料

点击右上角“搜索”，输入印文、地名或行政归属，例如“临淄”“守印”“仓府”“泰山郡”。结果分为代表藏品和区县图录。点击结果可跳到对应卡片，或打开完整图录。

## 数字手卷

“认识封泥”用八幕手卷说明一封古代文书怎样写下、系绳、覆泥、钤印、传递和验封。

电脑上可用左右箭头翻阅，也可以把鼠标移到手卷上滚动或拖动。点击手卷后，还能用键盘方向键翻阅。手机上左右滑动即可。

点击手卷下方的封泥图片，可查看图鉴中的对应藏品。

## 故事和图鉴

“封泥故事”有四篇短文，内容涉及秦代宫廷日常、陈介祺与金石考证、齐都故城的地方制度，以及仓府、盐铁和水运。

“齐鲁封泥图鉴”展示代表藏品。每张卡片列有图片、年代、研究价值和简要说明。点击卡片底部按钮后，网站会打开完整图录：选择临淄守印时，网站会直接定位到临淄资料；选择其他藏品时，网站会按相关印文查找。没有同名条目时，图录会明确提示。

## 地图和完整图录

“调研足迹”收录 45 个现代县区。地图上方可以筛选青州、兖州、徐州等历史行政体系，也可以在“精细立体版”和“简化平面版”之间切换。

点击地图上的圆点，详情区会显示现代地点、古代归属和资料数量。电脑上详情位于地图右侧，手机上位于下方。再点“在完整图录中查看”，可阅读相关印文、说明和补充史料。

你可以拖动立体地图来平移视图，在电脑上用滚轮缩放，在手机上用双指缩放。右侧滑块用于调整观察角度。单击复位按钮或双击地图后，地图会恢复初始位置、缩放和角度。

浅色线是现代市界，上方筛选按钮对应的则是历史行政体系。蓝色水域示意黄河、大汶河、徒骇河、小清河、沂河、潍河、大沽河、京杭运河山东段和微山湖。部分河段按参考图补绘，湖岸也经过概化，宽度和深度不是实测值。地图不能用于测绘、导航或行政勘界。

## 课程资源

课程区有三课时课件、原始 PDF、教案学习单和一段支教活动回顾视频。

切换课时后，可以用左右按钮、方向键、鼠标滚轮或拖动课件来翻页。课件上方的细进度条也能点击和拖动。视频使用浏览器自带控件，可以播放、暂停、调音量、全屏或拖动进度条跳到其他位置。

## 封泥牌具

“封泥牌具”展示麻将和扑克牌 3D 模型。拖动模型可以旋转，滚轮可以缩放，双击或点击“翻到背面”可以翻面。界面还提供类型切换、上一件、下一件、自动旋转、复位和全屏按钮。

手动拖动模型后，自动旋转会暂停，需要时可点击“自动旋转”重新开启。

## 印小灵与图片上传

点击右下角的印小灵可打开快捷对话。需要上传图片时，使用“问问 AI”栏目的完整对话区。两个入口都可以询问封泥、古文字、官制和历史地理。

你可以在完整对话区一次上传最多 4 张 JPEG、PNG 或 WebP 图片，每张不超过 5 MB。网站会将问题和图片发送给 AI 服务处理，请勿上传身份证件、联系方式等敏感信息。

AI 回答只适合辅助学习。残字释读、年代判断和有争议的历史问题，仍应以考古报告、图录和专业研究为准。

## 音乐

右上角音符按钮用于开启或暂停背景音乐。浏览器一般要求用户先点击一次页面，才允许播放声音。设置面板中还可以选择“古巷”“恩典”或“永恒”，调整音量、从头播放、切换下一首，或开启顺序轮播。视频播放时，背景音乐会自动暂停。

## 趣味问答

网站每轮最多抽取 10 道题。选择答案后点击“确认答案”，页面会显示对错和解析，你可以随后进入下一题。答完后可以查看得分、分享成绩或重新开始。

## 显示设置

点击齿轮按钮后，你可以调整主题、页面动效、卡片倾斜、背景微尘、开屏动画、音乐和印小灵。正文字号和行距固定使用默认值。动态效果中还可以开启或关闭鼠标尾迹，并调整颗粒大小和密度；移动端、触屏设备、系统减少动态效果或页面动效为 0 时，尾迹锁定关闭。选择昼夜自动主题时，网站在每天 06:00 至 18:00 使用浅色，其余时间使用深色。浏览器会保存这些设置，其他访客的页面不受影响。

## 遇到问题

- 地图空白：刷新页面，并确认浏览器支持 WebGL。也可以切到简化平面版。
- 视频不能拖动：先刷新页面。若仍无效，可能是网站服务端尚未更新，请联系维护者。
- AI 显示“连接失败，请稍后重试”：本次连接或请求失败。检查网络后重试；若一直失败，请把错误码和请求 ID 发给维护者。模型额度不足或配置异常也可能导致失败，不一定是你的网络问题。
- AI 显示“暂未确认连接状态”：网站尚未取得连接检查结果，可以尝试发送问题。无论 AI 是否可用，其他栏目都能继续浏览。
- 音乐没有播放：先点击页面任意位置，再点击音符按钮。
- 本地查看：开发者可在项目目录运行 `npm install` 和 `npm start`，然后访问 `http://127.0.0.1:3000`。如果直接双击 `index.html`，请先运行 `npm run compile:frontend` 或 `npm run build`，因为页面需要加载 TypeScript 编译后的 `.runtime/` 脚本；AI 和数据库功能仍需要启动 `server.js`。
