# 泥云智探｜网站使用说明

这是一份给普通访客准备的使用说明。如果你只是浏览网站，不需要了解项目代码；遇到不熟悉的名词时，跟着页面提示操作即可。

项目源码已开源在 [Windy-Field/Dirt](https://github.com/Windy-Field/Dirt)。

## 一、如何打开

网站有两种常见打开方式：

- **在线访问**：直接打开网站提供的正式网址。
- **本地访问**：在项目目录运行 `npm install` 和 `npm start`，再打开 `http://127.0.0.1:3000`。

也可以直接双击 `index.html` 浏览大部分静态内容。不过这种方式没有本地 API，数据库内容和 AI 对话可能无法使用；需要完整体验时，建议通过 Node 服务访问。

## 二、这是什么网站

“泥云智探”是一个面向公众、学生和传统文化爱好者的齐鲁封泥智慧人文平台。

你可以在这里：

- 了解封泥是什么，以及它在古代文书传递中的作用；
- 查看封泥实物、印文、年代和出土地等资料；
- 通过山东 3D 地图查看封泥资料的地理分布；
- 浏览数字手卷，了解一方封泥从制作到被发现的过程；
- 使用印小灵进行封泥知识问答和图片辅助观察；
- 体验扑克牌、麻将等封泥主题 3D 牌具；
- 学习开源研学课程；
- 通过趣味问答检验自己的学习成果。

## 三、首次进入网站

打开网站后，可能会先看到“封泥解缄”开屏动画。动画表现的是一幅古卷逐渐展开、封泥破坏、资料展厅开启的过程。

开屏动画结束后会自动进入网站首页。如果不想每次等待开屏动画，可以打开右上角的“显示设置”，取消“开启开屏动画”。关闭后，刷新页面会直接进入网站正文，不再显示卷轴、进度条或加载提示。

## 四、首页怎么浏览

### 1. 顶部导航

顶部导航可以直接跳转到对应栏目：

- 文物调研
- 认识封泥
- 封泥故事
- 齐鲁封泥文化
- 调研足迹
- 我们的工作
- 支教开源课程
- 封泥牌具
- 问问 AI
- 趣味问答

在手机或较窄的窗口中，导航会收进中间的菜单按钮。点击菜单按钮即可展开导航。

### 2. 搜索

点击右上角“搜索”，可以搜索封泥藏品和图录资料。

可以尝试搜索：

```text
临淄
守印
仓府
泰山郡
齐大官丞
```

搜索结果分为代表藏品和区县金石图录。点击结果后，网站会自动跳转到对应内容；图录结果还可以进一步打开地图位置。

## 五、文物调研

“文物调研”栏目介绍平台如何整理封泥资料，包括：

- 观察泥质、印面凹凸和残损；
- 记录系绳压痕等封缄细节；
- 走访博物馆和专业场馆；
- 对照古文字、官制和历史地理资料；
- 将资料整理成数字档案。

这里的重点不是只看一张图片，而是了解一枚封泥如何变成一份可信的研究资料。

## 六、认识封泥：数字手卷

“认识封泥”中的数字手卷介绍一封古代文书的完整旅程。

手卷支持以下操作：

- 点击左右箭头查看上一幕和下一幕；
- 在手卷区域左右拖动；
- 使用鼠标滚轮横向翻阅；
- 点击手卷区域后使用键盘左右方向键翻阅；
- 在手机上可以直接左右滑动。

手卷内容大致包括：

```text
简册书写
→ 系绳固定
→ 填覆澄泥
→ 官印钤压
→ 驿路传递
→ 验封破泥
→ 金石重光
```

手卷中的实物图、拓本和示意场景分别承担不同作用：有的展示真实资料，有的用于帮助理解制作过程。

## 七、封泥故事

“封泥故事”栏目以故事方式讲解封泥的历史。

点击故事卡片，可以打开对应的详细内容。故事中涉及的“印模”“封泥”“金石学”等概念，可以结合上下文阅读，不需要提前掌握专业知识。

## 八、齐鲁封泥文化与图录

在藏品区域可以查看封泥资料卡片。

每张资料卡通常包含：

- 名称；
- 年代或时期；
- 学术价值；
- 出土地或收藏线索；
- 简要说明；
- 查看调研档案入口。

点击“查看调研档案”可以查看更详细的信息。

“45 区县金石图录索引”默认只展示部分资料。点击“查看完整图录”后，可以在弹窗中筛选全部资料，支持按现代区县、古地名、官印印文和行政归属查询。

## 九、山东 3D 文化地图

地图展示山东封泥资料的地理分布。地图上的圆点代表封泥著录或出土资料点位。

### 地图操作

- 拖动地图：移动地图视角；
- 鼠标滚轮：放大或缩小地图；
- 双击地图：复位地图视角；
- 点击圆点：查看地点详情；
- 点击右上角复位按钮：恢复默认视角；
- 拖动右侧“抬升”滑杆：改变 3D 地形的抬升角度。

### 地图筛选

地图上方可以按照行政体系筛选：

- 全部；
- 青州体系；
- 兖州体系；
- 徐州体系；
- 其他标注。

筛选后，地图点位和下方资料会同步变化。

地图中的 DEM 地形用于文化展示和地理理解，不是测绘、导航或工程计算工具。

## 十、支教开源课程

课程栏目用于学习封泥、古文字和齐鲁文化相关知识。

点击左侧课程列表后，右侧会更新当前课程标题、课次、时长和简介。如果配置了课程视频，视频会在当前页面内播放；如果暂未配置视频，页面会提示视频接口已预留。

课程视频开始播放后，背景音乐会立即暂停。视频暂停或播放结束后，如果背景音乐在视频开始前处于播放状态，网站会恢复背景音乐。

## 十一、封泥牌具 3D 展厅

“封泥牌具”栏目展示扑克牌和麻将主题 3D 样机。

### 牌具操作

- 拖动模型：旋转模型；
- 鼠标滚轮：缩放模型；
- 双击模型：翻到另一面；
- 点击“扑克牌”或“麻将”：切换牌具类型；
- 点击上一件或下一件：浏览同类牌具；
- 点击“暂停旋转”：控制自动旋转；
- 点击“复位”：恢复模型默认视角；
- 点击“全屏”：进入全屏展台。

模型下方没有投影阴影，这是为了让贴图和封泥文字更清楚，材质高光和立体效果仍然保留。

## 十二、印小灵常驻助手

印小灵是页面右下角的常驻 AI 宠物。

### 打开快捷对话

点击右下角的印小灵，可以打开快捷 AI 对话框。

快捷对话支持：

- 输入文字提问；
- 点击快捷问题；
- 查看最近的回答；
- 点击右上角 `↻` 清空对话；
- 点击 `×` 收起窗口。

快捷对话使用网站已有的 AI 接口。问题较复杂时，也可以滚动到页面下方的完整 AI 栏目继续交流。

### 拖动印小灵

按住印小灵并拖动，可以改变它在当前页面中的位置。

位置会保存为相对坐标，因此：

- 刷新后仍会回到上次停留的大致位置；
- 浏览器窗口改变大小后会重新计算位置；
- 浏览器缩放后仍会尽量保持相同的相对位置；
- 宠物不会被拖出屏幕范围。

### 动态语录

印小灵旁边的短句会根据时间和当前状态变化。例如早上、下午、晚上和深夜会使用不同的问候语；AI 思考或回答时也会显示对应状态。

## 十三、完整 AI 导览

页面下方的 AI 区域适合进行较完整的交流。

可以：

- 输入封泥相关问题；
- 上传一张或多张封泥图片；
- 请求印文候选释读；
- 询问封缄方式、官制、历史地理和金石学知识；
- 点击快捷问题快速开始。

图片分析结果只作为辅助研学参考。对于模糊、残缺或有争议的古文字，AI 不能替代专业文博或古文字专家的正式鉴定。

点击完整 AI 栏目右上角的 `↻` 可以清空当前对话。

## 十四、趣味问答

趣味问答每轮随机抽取题目，通常为十道题，每题十分。

答题流程：

1. 选择一个答案；
2. 点击“确认答案”；
3. 查看对错和解析；
4. 继续下一题；
5. 完成后查看总分和答对题数。

答完后可以点击“再来一轮”重新开始，也可以点击“分享成绩”复制当前页面网址。

长选项会自动切换成更适合阅读的单列布局，不需要手动调整。

## 十五、显示设置

点击右上角齿轮按钮可以打开“显示设置”。

### 阅读显示

- 色彩主题：汉白玉、墨玉、按时自动；
- 正文字号：小、标准、大；
- 行间距：紧凑、舒适、宽松。

### 深色模式

“墨玉”就是网站的深色模式，适合夜间阅读或希望降低页面亮度时使用。它会把宣纸色页面切换为玄青墨玉色，同时调整文字、边框、朱砂强调色和弹窗遮罩的明暗关系，保证内容仍然清楚可读。开屏动画、文物图片、数字手卷、山东 3D 地图、3D 牌具、AI 对话、趣味问答和滚动条也会同步适配，不需要分别设置。

打开右上角齿轮按钮，在“显示设置”的“色彩主题”中选择：

- **汉白玉**：固定使用浅色模式，页面以宣纸、泥土和朱砂色为主；
- **墨玉**：固定使用深色模式，页面以玄青、墨玉、青铜和较亮的朱砂色为主；
- **昼夜自动**：按照浏览器所在设备的本地时间自动切换。每天 `06:00`（含）至 `18:00`（不含）使用浅色，其余时间使用深色。

主题选择会保存在当前浏览器中，刷新页面后仍会保留。自动模式会在 `06:00` 和 `18:00` 附近自动更新；如果页面曾经处于后台，重新回到页面时也会重新检查时间。主题设置不会上传到服务器，也不会影响其他用户。

### 动态效果

- 页面动效强度：控制页面整体动画程度；
- 卡片倾斜角度：控制鼠标悬停时的卡片立体倾斜；
- 背景微尘数量：控制页面背景中的微尘数量。
- 背景微尘速度：控制背景微尘的漂移速度，设为“静止”即可保留微尘但停止运动。

### 智能助手

- 开启开屏动画：控制刷新页面时是否显示卷轴开场；
- 显示宠物：控制印小灵是否常驻页面；
- 开启宠物动态语录：控制宠物旁边的动态提示语。

### 音乐设置

网站默认关闭背景音乐。可以使用两种方式控制音乐：

- 点击顶部导航栏搜索按钮和设置按钮之间的音符 `♪`，快速播放或暂停音乐；
- 打开右上角“显示设置”，在“音乐”区域进行完整设置。

音乐设置包括：

- **开启背景音乐**：开启或关闭背景音乐；
- **古 巷**：播放 `lane.mp3`，位于最左侧选项；
- **恩 典**：播放 `amazingGrace.mp3`，位于中间选项；
- **永 恒**：播放 `eternal.mp3`，位于最右侧选项；
- **从头播放** `↺`：将当前歌曲进度归零，并从头开始播放；
- **音乐轮播** `⇄`：开启后，歌曲按“古巷 → 恩典 → 永恒”的顺序自动切换；关闭后，当前歌曲会单曲循环；
- **下一首** `→|`：跳过当前歌曲，直接从头播放下一首；即使轮播关闭，也可以手动使用；
- **音乐音量**：调整背景音乐音量，默认音量为 `3%`。

选中的歌曲和轮播状态会保存在当前浏览器中。《永恒》使用独立的较低音量系数，默认约为其他歌曲整体音量的一半。点击“恢复默认”后，音乐会关闭，音量恢复为 `3%`，歌曲恢复为“古巷”，轮播关闭。

音乐优先级高于普通页面效果，但低于视频：只要页面内视频开始播放，背景音乐就会立即暂停；视频停止后，只有视频播放前音乐正在播放时才会自动恢复。切换浏览器窗口或暂时离开网页不会主动暂停背景音乐。

点击“恢复默认”会恢复页面显示设置，并重新开启开屏动画、印小灵和动态语录，同时关闭背景音乐、恢复 `3%` 音量、选择“古巷”并关闭音乐轮播。

系统开启“减少动态效果”时，网站会自动降低或关闭部分动画，但不会影响主要浏览和问答功能。

## 十六、常见问题

### 页面打开后一直在加载怎么办？

开屏层有最长等待时间。如果部分资料接口暂时不可用，页面会继续打开，并提示部分资料稍后加载。

可以在右上角设置中关闭开屏动画，之后刷新页面直接进入正文。

### 地图没有显示完整怎么办？

请等待地图初始化完成，或刷新页面重试。地图支持双击复位，也可以使用右上角复位按钮恢复视角。

### AI 没有回答怎么办？

可能是 AI 服务未连接、网络不可用或服务端没有配置 API Key。

可以先尝试：

- 检查网络连接；
- 刷新页面；
- 使用本地部署的 Node 服务；
- 稍后再次提问。

## 十八、使用提醒

- 地图内容用于文化展示，不用于测绘或导航；
- AI 结果用于辅助学习，不等同于专家鉴定；
- 上传图片前请确认图片中不包含不希望发送到 AI 服务的隐私信息；
- 直接打开本地 `index.html` 时，数据库、AI 和部分网络能力可能不可用；
- AI 图片分析只是辅助学习，不能替代文博、古文字或医学等专业鉴定；
- 上传图片前，请确认图片中没有身份证件、联系方式、未公开文稿等隐私信息；
- 如果网站部署到公网，应使用稳定的 HTTPS 地址，并避免在公开页面填写 API Key、密码或其他密钥。

## 十九、浏览器与权限

建议使用较新的 Chrome、Edge、Safari 或 Firefox。第一次使用以下功能时，浏览器可能会询问权限：

- 播放背景音乐或课程视频：需要允许页面播放声音；浏览器通常要求先点击页面后才能自动播放；
- AI 图片分析：需要允许选择本地图片，图片会按照网站服务端的配置发送给 AI 服务；
- 3D 地图和牌具展厅：需要浏览器支持 WebGL。若模型区域空白，可以先更新浏览器、关闭过度严格的脚本拦截，再刷新页面。

如果使用 Safari，请确认没有关闭 JavaScript、WebGL 或网站的本地存储功能。主题、音乐、宠物位置等偏好保存在当前浏览器的本地存储中；清除网站数据后，这些设置会恢复默认，但不会影响其他访客。
